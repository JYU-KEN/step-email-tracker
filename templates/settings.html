⚙️ Wix API 設定

WixのAPIキーとサイトIDを入力してください

APIキーの取得方法：
1. Wixダッシュボード → 左メニュー「設定」
2. 「詳細設定」→「API Keys」
3. 「Generate API Key」→ Email Marketing の権限をON
4. 生成されたキーをコピー

サイトIDの取得方法：
Wixダッシュボードの URL に含まれる UUID
例: dashboard/8c62a8d6-xxxx-xxxx-xxxx-xxxxxxxxxxxx/...
